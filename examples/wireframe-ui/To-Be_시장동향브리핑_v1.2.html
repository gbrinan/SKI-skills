스킬 템플릿 채움 힌트

완성된 스킬 본문이 아니라, 제작 에이전트가 입력·출력·규칙·예외·사람 개입·테스트를 어디서 시작할지 알려주는 인수인계입니다.

01

시장 자료 정규화기

공유 폴더와 구독 메일의 원문 목록을 받아 제목·출처·URL·작성일이 정리된 목록을 만든다.

실행 순서

  1. 원문 목록 조회
  2. 필드 존재 여부 확인
  3. 표기 정규화

판단 규칙

  • 제목·출처·URL·작성일을 같은 형식으로 맞춘다.

예외와 사람 개입

  • 권한이 없거나 표기를 해석할 수 없으면 사람이 확인한다.
  • 자동 조회할 수 없는 유료 사이트·종이 문서는 담당자가 공유 폴더에 준비한다.

테스트 예시

  • 입력 URL 표기가 다른 기사 2건
    기대 정규화된 URL과 원문 출처가 함께 남는다.

제작 전에 확인

  • 구독 메일과 공유 폴더의 실제 접근 권한
02

중요 기사 선별기

표준 기사 목록을 받아 중복을 묶고 중요 기사 후보와 사람 검토 목록을 만든다.

실행 순서

  1. 중복 묶기
  2. 주제 적합도 분류
  3. 애매 기사 검토 대기

판단 규칙

  • 정규화 URL이 같으면 제목이 달라도 같은 기사로 묶는다.
  • 브리핑 주제와 직접 관련된 기사만 후보로 표시한다.

예외와 사람 개입

  • 출처 또는 URL이 없으면 자동 제외하지 않는다.
  • 주제 적합도가 애매하면 사람 검토로 보낸다.
  • 담당자가 애매한 기사의 포함 여부와 근거를 기록한다.

테스트 예시

  • 입력 제목은 다르지만 정규화 URL이 같은 기사 2건
    기대 한 기사 묶음으로 표시된다.
  • 입력 출처가 없는 기사
    기대 자동 제외 대신 사람 검토 목록에 들어간다.

제작 전에 확인

  • 브리핑 주제 목록의 관리 주체
03

시장 브리핑 초안기

선별 확정 기사를 받아 근거 문장이 연결된 시사점과 주간 브리핑 초안을 만든다.

실행 순서

  1. 근거 문장 추출
  2. 시사점 작성
  3. 브리핑 초안 작성

판단 규칙

  • 근거 문장이 없는 시사점은 초안에 넣지 않는다.

예외와 사람 개입

  • 해석이 충돌하거나 근거가 누락되면 사람 검토로 보낸다.
  • 담당자가 사실·톤·공유 범위를 확인하고 최종 확정한다.

테스트 예시

  • 입력 근거 문장이 없는 시사점
    기대 초안에서 제외되고 보완 필요로 표시된다.

제작 전에 확인

  • 실제 브리핑 양식과 필수 섹션
가상 데이터 · 외부 전송 없음 · 사람의 최종 확정 유지
