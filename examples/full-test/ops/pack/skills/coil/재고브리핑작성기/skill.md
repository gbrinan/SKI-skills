# 재고 브리핑 작성기

> 상류: 와이어프레임 `재고점검-1-3` · 담당 (미정) · 업무 Lv6 「처리 방안 결정 (폐기·이관·발주)」

## 판단기준·예외 (와이어프레임에서 옮김)
- **점검 브리핑 구성** [코덱스] — 이상 재고 목록을 요약해 월간 점검 브리핑 초안을 만든다
  - 예외: 이상 0건이면 정상 확인 브리핑으로 낸다
- **처리 방안 결정·승인** [사람] — 담당자·팀장이 브리핑을 보고 처리 방안을 결정한다 — 자동 처리하지 않는다

## 사람이 확인하고 멈추는 지점
- 처리 방안 결정·승인 — 여기서 확인을 요청하고 멈춘다. 자동 발송하지 않는다.
