# 재고 대사 체커

> 상류: 와이어프레임 `재고점검-1-1` · 담당 (미정) · 업무 Lv6 「재고 현황 추출·장부 대사」

## 판단기준·예외 (와이어프레임에서 옮김)
- **재고 현황·장부 파일 조회** [MCP·조회] — 공유폴더의 재고 현황과 장부 파일을 읽는다
  - 예외: 파일 없으면 담당자에게 확인 — 사람
- **ERP 재고 원장 조회** [API] — —
  - 예외: 오늘 실행 불가 — 사람이 수기 추출한다
- **품목별 수량 대사** [코덱스] — 현황 수량과 장부 수량이 같으면 → 일치 / 다르면 → 차이 플래그
  - 예외: 단위가 다르면 환산 후 대사, 환산 불가면 사람 확인
- **대사 결과표 작성** [코덱스] — 품목·현황·장부·차이를 표로 만든다
  - 예외: 차이 0건이어도 표는 낸다
