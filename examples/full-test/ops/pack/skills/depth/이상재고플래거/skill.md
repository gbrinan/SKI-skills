# 이상 재고 플래거

> 상류: 와이어프레임 `재고점검-1-2` · 담당 (미정) · 업무 Lv6 「이상 재고(과잉·부족·장기) 식별」

## 판단기준·예외 (와이어프레임에서 옮김)
- **기준 대비 판정** [코덱스] — 적정 재고 대비 {과잉률}% 이상 → 과잉 / 안전재고 미만 → 부족 / 최종 출고 후 {경과일}일 초과 → 장기 (기준값은 실행 시 지정)
  - 예외: 판정 애매하면 목록에 올리고 사유를 적는다
- **이상 재고 목록 작성** [코덱스] — 유형(과잉·부족·장기)별로 목록을 만들고 근거 수치를 붙인다
- **처리 후보 초안 붙이기** [코덱스] — 과거 처리 사례가 있으면 처리 후보(폐기·이관·발주)를 초안으로 붙인다 — 사례 없으면 빈칸
  - 예외: 결정은 사람이 한다
