## 4. 대표 시나리오
- 트리거: 월말 재고 점검, 재고 현황 폴더를 지정
- 입력: 재고현황 → 처리: 대사·이상 식별·브리핑 → 출력: 대사결과 · 이상재고 · 점검브리핑
- 파이프라인: 재고대사체커 → 이상재고플래거 → 재고브리핑작성기

## 7. 검증·휴먼인더루프 지점
- 점검브리핑은 확인 요청으로 끝난다 — 처리 방안(폐기·이관·발주) 결정은 사람이 한다
- 판정 기준(과잉률·경과일)은 실행 시 지정하는 커스텀 값
