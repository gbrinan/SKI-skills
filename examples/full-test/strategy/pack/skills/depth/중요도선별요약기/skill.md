# 중요도 선별 요약기

> 상류: 와이어프레임 `동향브리핑-1-2` · 담당 (미정) · 업무 Lv6 「중요도 선별·요약」

## 판단기준·예외 (와이어프레임에서 옮김)
- **중요도 판정** [코덱스] — 자사·계열사 직접 언급 → 올림 / 경쟁사·규제 동향 → 올림 / 둘 다 아님 → 제외
  - 예외: 판정 애매하면 올린다
- **기사 요약 작성** [코덱스] — 올림 기사마다 3문장 요약과 시사점 1문장을 쓴다
  - 예외: 원문 접근 불가면 제목만 싣고 표기한다
- **선별 요약본 작성** [코덱스] — 중요도 순으로 정렬해 요약본을 만든다
  - 예외: {M건} 미만이면 그대로 낸다 (M은 실행 시 지정)
