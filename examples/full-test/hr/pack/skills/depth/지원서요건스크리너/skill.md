# 지원서 요건 스크리너

> 상류: 와이어프레임 `서류전형-1-1` · 담당 (미정) · 업무 Lv6 「지원서 요건 대조 (자격·경력)」

## 판단기준·예외 (와이어프레임에서 옮김)
- **지원서 묶음 조회** [MCP·조회] — 채용포탈에서 내려받은 지원서 묶음과 공고 요건을 읽는다
  - 예외: 파일 형식 이상 시 사람이 확인한다
- **필수요건 대조 판정** [코덱스] — 필수 자격·경력 미달 → 미달 / 충족 → 통과 / 서류만으로 판단 불가 → 애매
  - 예외: 애매 건은 현업 부서장 의견을 받는다
- **요건 대조표 작성** [코덱스] — 통과·미달·애매 3분류 표를 만든다
  - 예외: 전원 통과여도 표는 낸다
