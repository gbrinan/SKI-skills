# 직무적합성 소견 초안기

> 상류: 와이어프레임 `서류전형-1-2` · 담당 (미정) · 업무 Lv6 「우대사항·직무적합성 검토」

## 판단기준·예외 (와이어프레임에서 옮김)
- **통과자 지원서·직무기술서 대조** [코덱스] — 요건 통과자의 경력·프로젝트를 직무기술서 항목과 대조한다
  - 예외: 직무기술서 없으면 현업에 요청 — 사람
- **적합성 소견 판정** [코덱스] — 우대사항 {K개} 이상 부합 → 상 / 직무 경력만 부합 → 중 / 근거 부족 → 하 (K는 실행 시 지정)
  - 예외: 판정 애매하면 하 대신 사람 검토로 넘긴다
- **소견 초안 작성** [코덱스] — 후보별 소견 3~4문장 초안을 만든다 — 근거 없는 문장 금지
- **소견 확정** [사람] — 채용 담당자가 검토·확정한다

## 사람이 확인하고 멈추는 지점
- 소견 확정 — 여기서 확인을 요청하고 멈춘다. 자동 발송하지 않는다.
