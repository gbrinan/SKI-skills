# 합불 통보 초안기

> 상류: 와이어프레임 `서류전형-1-3` · 담당 (미정) · 업무 Lv6 「합격/불합격 통보」

## 판단기준·예외 (와이어프레임에서 옮김)
- **확정 소견·합불 목록 취합** [코덱스] — 확정된 소견과 합불 목록을 읽는다
  - 예외: 미확정 건이 있으면 멈추고 사람에게 알린다
- **통보 메일 초안 생성** [MCP·작성] — 합격·불합격 템플릿에 이름·일정만 채운다 — 사유는 쓰지 않는다
  - 예외: 발송은 사람이 한다
- **발송·확정** [사람] — 담당자가 초안 확인 후 발송한다

## 사람이 확인하고 멈추는 지점
- 발송·확정 — 여기서 확인을 요청하고 멈춘다. 자동 발송하지 않는다.
