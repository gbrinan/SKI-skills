- 작성: 예시 생성기 (회계관리팀 실물 산출물의 구조를 따름)
- 일자: 2026-08-24
- 용도: 디자인 캠프 해설 코치 / 에이전트, 스킬 설계 코치의 **연습·데모 입력**
- ⚠️ **본 문서의 모든 업무 내용·수치는 [예시]**

## 1. 개요

| 항목 | 내용 |
|---|---|

## 4. Pain Point & AX 매핑 [예시]

| PP ID | 유형 | 제목 | 심각도 | 매핑 |
|---|---|---|---|---|
| PP-O1 | MAN | 견적서 양식 제각각 — 비교표 수작업 작성 | **높음** | A-O1-1-1-2 |
| PP-O2 | RPT | 발주서 작성 반복 (유사 품목 재입력) | 중간 | A-O1-1-2-1 |
| PP-O3 | MAN | 협력사 실적 데이터 취합 수작업 (ERP+Excel 혼재) | **높음** | A-O1-2-1-1 |
| PP-O4 | ERR | 입고 예정 vs 실입고 수동 대사 — 누락·중복 오류 | **높음** | A-O2-1-1-1 |
| PP-O5 | MAN | 재고 장부 대사 Excel 수작업 | **높음** | A-O2-2-1-1 |
| PP-O6 | SILO | 이상 재고 처리 기준 속인화 | 중간 | A-O2-2-1-3 |
| PP-O7 | MAN | 정비 실적 수기 취합 (CMMS 미입력분 존재) | **높음** | A-O3-1-1-1 |
| PP-O8 | RPT | 월간 정비 리포트 편집 반복 | 중간 | A-O3-1-1-3 |
| PP-O9 | WAIT | 개선과제 진척 취합 지연 — 독촉 반복 | 중간 | A-O4-1-2-1 |
| PP-O10 | SILO | SOP가 최신화 안 됨 — 담당자 머릿속 기준 | 중간 | A-O4-2-1-1 |
| PP-O11 | MAN | 주간 보고 취합→PPT 수동 이관 | 중간 | A-O5-1-1-1~2 |
| PP-O12 | CHG | 고장 원인 분류 기준이 사람마다 다름 | 중간 | A-O3-1-1-2 |

**기존 AX**: AX-O1 발주 승인 전자결재 자동 라우팅 (운영 중) — T-O1-1-2 / AX-O2 재고 부족 자동 알림 (운영 중, 기준 미세조정 필요) — A-O2-2-1-2
**AX화 추천 (8개)**: A-O1-1-1-2, A-O1-2-1-1~2, A-O2-1-1-1, A-O2-2-1-1~2, A-O3-1-1-1~3, A-O4-1-2-1, A-O5-1-1-1~2
**우선순위 상위**: 🔴1 T-O1-1-1 견적 접수·비교(PP-O1) · 🔴2 T-O2-2-1 재고 점검(PP-O5·O6) · 🟠3 T-O3-1-1 정비 실적 관리(PP-O7·O8·O12)

## 5. As-Is Flow (핵심 프로세스) [예시]

**[T-O1-1-1 견적 접수·비교] (분기 B1 · 루프백 L1, HITL 2) — 주간 수 건 반복**
```
● 시작 (구매요청서 접수)
→ A-O1-1-1-1 사양 확인
◆ 사양 불명확?
  Yes → ↩ 요청 부서에 보완 요청 (L1)
  No  → (계속)
→ A-O1-1-1-2 견적서 항목 정리·비교표 작성
→ A-O1-1-1-3 업체 선정 품의 [HITL 선정 판단·승인]
■ 종료
```

**[T-O2-2-1 재고 점검] (분기 B2 · 루프백 L2, HITL 2) — 월간**
```
● 시작 (월말)
→ A-O2-2-1-1 재고 현황 추출·장부 대사
◆ 차이 발견?
  Yes → 원인 추적 [HITL] ↩ 재대사 (L2)
  No  → (계속)
→ A-O2-2-1-2 이상 재고(과잉·부족·장기) 식별
→ A-O2-2-1-3 처리 방안 결정 [HITL — 기준 속인화]
■ 종료
```
