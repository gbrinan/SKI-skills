## 5. As-Is Flow (핵심 프로세스) [예시]

**[T-S4-1-1 동향 브리핑] (분기 B1, HITL 1) — 주간 반복**
```
● 시작 (매주 월)
→ A-S4-1-1-1 뉴스·공시·리포트 수집 (여러 소스 순회)
→ A-S4-1-1-2 중요도 선별·요약 [HITL 판단]
◆ 심층 검토 필요 이슈?
  Yes → 담당 임원 별도 보고
  No  → (계속)
→ A-S4-1-1-3 주간 브리핑 발행
■ 종료
```

**[T-S2-1-2 부문 계획 취합·검증] (분기 B2 · 루프백 L1, HITL 2) — 연 1회지만 부문 수 × 라운드 반복**
```
● 시작 (부문 제출 마감)
→ A-S2-1-2-1 부문별 제출본 버전 취합
→ A-S2-1-2-2 논리·수치 정합성 검증 [HITL]
◆ 오류·논리 결함 발견?
  Yes → A-S2-1-2-3 조정 협의·재제출 요청 [HITL] ↩ 재취합 (L1)
  No  → 전사 통합으로 전달
■ 종료
```
