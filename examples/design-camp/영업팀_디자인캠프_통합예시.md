## 4. Pain Point & AX 매핑 [예시]

|---|---|---|---|---|
| PP-B1 | RPT | 견적서 작성 반복 — 유사 사양 재입력, 주간 수 건 | **높음** | A-B1-1-1-3 |
| PP-B2 | MAN | 원가·마진 검토 Excel 수작업 — 단가표 버전 혼선 | **높음** | A-B1-1-1-2 |
| PP-B3 | ERR | 발주서 vs 견적 조건 수동 대조 — 단가·수량 불일치 놓침 | **높음** | A-B1-1-2-1 |
| PP-B4 | RPT | 미팅 자료 준비 반복 (거래실적 추출→PPT) | 중간 | A-B2-1-1-1 |
| PP-B5 | MAN | 미팅록 수작업 정리·후속 누락 | 중간 | A-B2-1-1-3 |
| PP-B6 | SILO | 클레임 분류·보상 기준 속인화 | 중간 | A-B2-1-2-1 |
| PP-B7 | WAIT | 수요 계획 취합 지연 — 고객·지역별 양식 제각각 | **높음** | A-B3-1-1-1 |
| PP-B8 | ERR | 수요 계획 vs 실적 검증 수작업 — 이상치 놓침 | 중간 | A-B3-1-1-2 |
| PP-B9 | MAN | 여신 사용률 수동 추출·임박 알림 없음 | **높음** | A-B4-1-1-1~2 |

**우선순위 상위**: 🔴1 T-B1-1-1 견적 대응(PP-B1·B2) · 🔴2 T-B3-1-1 월간 수요 취합(PP-B7·B8) · 🟠3 T-B4-1-1 여신 한도 점검(PP-B9)

## 5. As-Is Flow (핵심 프로세스) [예시]

**[T-B1-1-1 견적 대응] (분기 B1 · 루프백 L1, HITL 2) — 주간 수 건 반복**
```
● 시작 (RFQ 접수)
→ A-B1-1-1-1 견적요청 접수·사양 확인
◆ 사양 불명확?
  Yes → ↩ 고객에 보완 요청 (L1)
  No  → (계속)
→ A-B1-1-1-2 원가·마진 검토 [HITL 마진 판단]
→ A-B1-1-1-3 견적서 작성
→ A-B1-1-1-4 견적 승인·발송 [HITL 승인]
■ 종료
```

**[T-B3-1-1 월간 수요 취합] (분기 B2 · 루프백 L2, HITL 1) — 월간**
```
● 시작 (월말 D-5)
→ A-B3-1-1-1 고객별 수요 계획 취합
◆ 미제출·양식 오류?
  Yes → ↩ 재요청 후 대기 (L2)
  No  → (계속)
→ A-B3-1-1-2 전월 실적 대비 검증
→ A-B3-1-1-3 공장 배분 협의 [HITL]
■ 종료
```
