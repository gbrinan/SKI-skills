## 5. As-Is Flow (핵심 프로세스) [예시]

**[T-H1-1-2 서류전형] (분기 B1 · 루프백 L1, HITL 2)**
```
● 시작 (공고 마감)
→ A-H1-1-2-1 지원서 요건 대조 (자격·경력)
◆ 요건 미달?
  Yes → 불합격 분류
  No  → A-H1-1-2-2 우대사항·직무적합성 검토 [HITL]
◆ 판단 애매?
  Yes → ↩ 현업 부서장 의견 요청 후 재검토 (L1)
→ A-H1-1-2-3 합격/불합격 통보 [HITL 최종 확인]
■ 종료
```

**[T-H4-2-1 급여 마감] (분기 B2 · 루프백 L2, HITL 2)**
```
● 시작 (근태 확정)
→ A-H4-2-1-1 급여 기초자료 반영
→ A-H4-2-1-2 전월 대비 차이 검증
◆ 설명 안 되는 차이 발견?
  Yes → 원인 추적·수정 [HITL] ↩ 재검증 (L2)
  No  → A-H4-2-1-3 급여 확정·이체 승인 [HITL]
■ 종료
```
