# 기업교육 강의안 제작 스킬

## Background

기업교육 강의안은 학습 목표, 시간, 실습, 시각 자료, 진행자 노트를 함께 설계해야 하며 사용자마다 강의 분야와 표현 선호가 다르다.

## Goal

특정 회사 브랜드에 종속되지 않은 강의안 제작 스킬과 재사용 가능한 사용자 프로필 입력부를 제공한다.

## How it works

스킬은 현재 요청과 첨부 자료를 구분하고, 사용자 프로필을 기본값으로 적용한 뒤 학습 흐름과 슬라이드를 설계·제작·검수한다. 현재 요청과 고객 요구가 프로필보다 항상 우선한다.
