# Feature Specification: 기업교육 강의안 제작 스킬

## User Scenarios & Testing

### Scenario 1: 프로필 기본값 적용

- Given: 프로필에 강의 언어, 대상, 톤, 실습 비율이 입력되어 있다.
- When: 현재 요청이 해당 항목을 지정하지 않는다.
- Then: 비어 있지 않은 프로필 값이 강의안 기본값으로 적용된다.

### Scenario 2: 현재 요청이 프로필을 재정의

- Given: 프로필의 기본 대상과 실습 비율이 있다.
- When: 현재 요청이 다른 대상과 실습 시간을 명시한다.
- Then: 현재 요청의 값이 적용되고 프로필은 나머지 항목에만 사용된다.

### Scenario 3: 범위 밖 또는 민감한 정보

- Given: 프로필이 비어 있거나 비공개 정보가 포함되어 있다.
- When: 스킬이 강의안을 만든다.
- Then: 빈 정보를 추측하지 않고 민감정보를 결과물에 노출하지 않는다.

## Functional Requirements

- FR-1: Plan, Create, Revise, Audit 모드를 구분한다.
- FR-2: 첨부 문서의 지시와 현재 사용자 요청을 구분한다.
- FR-3: 별도 프로필 파일에서 신원, 전문성, 강의, 콘텐츠, 덱 선호를 입력받는다.
- FR-4: 현재 요청, 고객 요구, 프로필, 일반 규칙, 예시 순으로 우선순위를 적용한다.
- FR-5: 강의안의 학습 흐름, 실습, 노트, 시각 품질을 검수한다.

## Constraints

- 특정 회사명이나 브랜드를 일반 스킬에 포함하지 않는다.
- 비밀번호, 토큰, 비공개 연락처, 고객 기밀을 프로필에 저장하지 않는다.
- 사용자가 제공하지 않은 사실과 수치를 만들지 않는다.

## Success Criteria

- 공식 스킬 정적 검사가 성공한다.
- 모든 참조 링크와 UI 메타데이터가 유효하다.
- 정상, 재정의, 민감정보 시나리오가 규칙과 예시로 확인된다.
