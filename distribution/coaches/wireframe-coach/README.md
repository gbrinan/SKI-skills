# 에이전트, 스킬 설계 코치 (wireframe-coach)

세션 4 · To-Be 설계 · 20~25분

## 무엇을 하나
머릿속에만 있던 판단 기준을 글로 꺼내 **AI가 실행할 수 있는 To-Be 와이어프레임**으로 다듬고, 만들 스킬 2~3개를 골라줍니다. 스킬 본문은 쓰지 않습니다.

## 입력 (셋 중 아무거나)
1. 앞 코치(디자인캠프 해설 코치)의 정리 블록 — 권장
2. 디자인캠프 md 파일
3. 말로 설명 — `성함 / 업무명 / 하위 태스크 / 입력 / 출력 / 사람이 하는 지점`

## 출력
- To-Be 와이어프레임(가로 트리) + 노드 상세 표(판단기준·예외)
- 추천 스킬 2~3개 (이름 + 한 줄 정의 + 우선순위)
- `To-Be_{액티비티명}.html`
- **`{액티비티명}-1-N_{스킬명}_와이어프레임.md`** — 추천 스킬마다 1개. 다음 코치가 바로 읽습니다
- 정리 블록

## 환경 아이콘
🧠 이노허브에서 처리 · 📥 회사 자료 읽기 · 📤 회사 도구에 저장 · 🚧 연결 준비 중 · 👤 사람

## 주의
- **발송·변경 앞에는 반드시 👤.** 메일은 초안(draft)까지가 기본입니다.
- 한 작업에 실행 방법이 두 개면 → 더 나누라는 신호입니다.
- 판단 기준을 지어내지 않습니다. 안 나오면 👤로 남깁니다.
- 스킬을 4개 이상 추천하지 않습니다. 늘리는 대신 줄입니다.
